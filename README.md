# Marina App - React Native ChatGPT Style

Мобильное приложение в стиле ChatGPT с системой аутентификации, построенное на React Native с TypeScript.

## 🚀 Возможности

- ✨ Современный дизайн в стиле ChatGPT
- 🔐 Система входа и регистрации
- 📱 Поддержка iOS и Android
- 🎨 Стилизация с помощью Tailwind CSS (NativeWind)
- ⚡ TypeScript для безопасности типов
- 🧪 Валидация форм
- 📊 Индикатор силы пароля
- 🔄 Состояния загрузки

## 🛠 Технологии

- **React Native** - Фреймворк для мобильной разработки
- **Expo** - Платформа для React Native
- **TypeScript** - Типизированный JavaScript
- **React Navigation** - Навигация между экранами
- **NativeWind** - Tailwind CSS для React Native
- **React Native Safe Area Context** - Безопасные области

## 📱 Структура приложения

```
src/
├── components/          # Переиспользуемые компоненты
│   ├── CustomInput.tsx  # Кастомный инпут
│   └── CustomButton.tsx # Кастомная кнопка
├── screens/            # Экраны приложения
│   ├── LoginScreen.tsx  # Экран входа
│   ├── RegisterScreen.tsx # Экран регистрации
│   └── MainScreen.tsx   # Главный экран
├── types/              # TypeScript типы
│   └── auth.ts         # Типы для аутентификации
└── utils/              # Утилиты
    └── validation.ts   # Функции валидации
```

## 🔧 Установка и запуск

1. **Клонируйте репозиторий**

   ```bash
   git clone <repository-url>
   cd MarinaApp
   ```

2. **Установите зависимости**

   ```bash
   npm install
   ```

3. **Запустите приложение**

   ```bash
   npm start
   ```

4. **Запустите на устройстве**
   - **iOS**: `npm run ios`
   - **Android**: `npm run android`
   - **Web**: `npm run web`

## 📋 Функционал экранов

### 🔑 Экран входа (LoginScreen)

- Поля для email и пароля
- Валидация в реальном времени
- Кнопка "Забыли пароль?"
- Вход через Google (заглушка)
- Переход на регистрацию

### 📝 Экран регистрации (RegisterScreen)

- Поля: имя, email, пароль, подтверждение пароля
- Индикатор силы пароля
- Чекбокс согласия с условиями
- Регистрация через Google (заглушка)
- Переход на вход

### 🏠 Главный экран (MainScreen)

- Приветственное сообщение
- Кнопки для дальнейшей навигации

## 🔍 Валидация

Реализованы следующие проверки:

- ✅ Email формат
- ✅ Длина пароля (минимум 8 символов)
- ✅ Совпадение паролей
- ✅ Длина имени (минимум 2 символа)
- ✅ Силы пароля (слабый/средний/сильный)
